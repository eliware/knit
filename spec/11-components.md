# Component Specifications

Shared components: StatusBadge, EnvironmentBadge, RunTimeline, TargetStage, LogPanel, EventTable, DataTable, FilterBar, EmptyState, ConfirmDialog, CommandPalette, HealthIndicator, AuditEntry, UserMenu.

Define loading, empty, error, disabled, access denied, mobile, keyboard, and reduced animation states for each component.

Show each status with color, an icon, text, and a label that assistive tools can read. LogPanel must support filters, follow mode, copy/download, grouping, redaction indication, and new-output markers.
