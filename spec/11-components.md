# Component Specifications

Shared components: StatusBadge, EnvironmentBadge, RunTimeline, TargetStage, LogPanel, EventTable, DataTable, FilterBar, EmptyState, ConfirmDialog, CommandPalette, HealthIndicator, AuditEntry, UserMenu.

Every component must define loading, empty, error, disabled, unauthorized, mobile, keyboard, and reduced-motion states where applicable.

Status must combine color, icon, text, and accessible label. LogPanel must support search, follow mode, copy/download, grouping, redaction indication, and new-output markers.
